# Aarman Arzare — Personal Portfolio

A beginner-friendly, responsive portfolio built with semantic HTML and CSS. The layout introduces Aarman and shares learning areas, project examples, interests, and achievements.

## Features

- Home, About, Education, Skills, Projects, Interests, Achievements, and Contact sections
- Responsive layout for desktop, tablet, and mobile screens
- Simple in-page navigation and hover styles
- Custom initials-based profile badge made with CSS
- No JavaScript, images, external libraries, or build tools required

## Run locally

Open `index.html` in a modern browser.

## Personalize

The school, contact, and project details can be edited in `index.html`. Project cards currently serve as simple examples; replace them with links and descriptions for your own published work.

## Files

- `index.html` — page content and sections
- `style.css` — colors, layout, cards, and responsive styles
