# Aarman Arzare — Personal Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript. It introduces Aarman, highlights learning areas and project work, and includes interactive navigation, a light/dark theme, and a client-side validated contact form.

## Features

- Home, About, Education, Skills, Projects, Interests, Achievements, and Contact sections
- Responsive desktop, tablet, and mobile layouts
- Smooth section navigation with an active section indicator
- Mobile navigation menu
- Light and dark themes with the selection saved in the browser
- Accessible form labels, keyboard focus styles, reduced-motion support, and client-side validation
- Custom CSS illustrations and favicon; no image downloads or build tools required

## Run locally

Open `index.html` in a modern browser. The site is static and does not need a server or dependencies.

## Personalize the content

The portfolio uses the name and GitHub profile supplied with the project request. The brief did not include school, email, awards, or project repository details, so the page avoids presenting invented personal history. Update the content in `index.html` as those details become available. The progress bars and sample project cards are editable examples; link them to your actual work before sharing the site as a finished profile.

The contact form validates the fields locally and displays a confirmation message. It does not send or store messages. A form service or backend would be needed to receive submissions.

## Files

- `index.html` — page content and section structure
- `style.css` — visual design, themes, and responsive layouts
- `script.js` — theme, navigation, and form interactions
- `favicon.svg` — small custom site icon
